# XAVEVR v2

Upgraded GitHub Pages storefront with dystopian animations and four audio preview placeholders.

Replace the four YOUR_STRIPE_* placeholders in index.html with your Stripe Payment Links. Replace the files in /audio with your real previews if desired. Keep paid product files private; do not put Stripe secret keys or protected downloads in this public repository.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
